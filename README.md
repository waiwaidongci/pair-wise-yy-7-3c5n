# 古船模型帆索校准

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 配重试航台（整船静载）

入口：页面顶部「配重试航台（整船静载）」，或直接访问 `/trials`。

业务代码按职责分为三处：

| 文件 | 职责 |
| --- | --- |
| `trial-rules.js` | 判定规则（唯一口径）：三档配重、偏移/回弹阈值、各状态流转的前置条件、结论签名 |
| `trial-store.js` | 记录层：试航单登记、事件流水、持久化、旧结论失效与交付闸口 |
| `trial-page.js` | 试航台页面（阈值与文案取自 `/api/trial-rules`，不复制判定口径） |

规则要点：

- 每艘模型只允许一份「进行中 / 停待修整」的试航单，登记三档配重（轻载/半载/满载）、保压时长和操作工。
- 三档均须合格才通过：保压中桅杆偏移 ≤ 2mm；卸重后残余偏移 ≤ 0.5mm（回弹达标）。
- 任一档不合格即「停待修整」；修整人不能是原操作工；修整后复测通过才恢复交付。
- 未取得有效通过结论不得把模型置为「已交付」；结论失效会自动撤回交付。
- 配重或帆索材料改动，旧通过结论立即置为「已失效」，需重新试航。
