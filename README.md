# 古船模型帆索校准

运行：

```bash
npm start
```

访问：

- 帆索校准台 `http://localhost:3038/`
- 配重试航台 `http://localhost:3038/trials`

数据保存在 `data/model-rigging-calibration.json`。

## 配重试航台规则

模型上支架后，必须先过整船静载试航才能报交付：

1. **每艘模型只留一份进行中的试航单**（进行中 / 待修整），重复开立会被拒绝。
2. 每轮登记**三档配重**（轻载 / 标准 / 重载），每档记录配重重量、**保压时长**、**桅杆偏移**，以及**操作工**；卸重后记录残余偏移（回弹）。
3. 任一档桅杆偏移 **> 2mm**，或卸重后残余偏移 **> 0.5mm**（回弹不达标），判定不合格，立即停待修整，模型状态置为「待修整」。
4. 修整人不能是该轮的原操作工；未登记修整不能复测。复测通过后模型恢复到「待复核」，门禁放行交付。
5. 配重配置或帆索材料一经改动，该模型已有合格结论自动标记失效，须重新试航；重新交付前门禁会再次拦截。

## 代码分层

试航业务按三处分开，互不越界：

| 关注点 | 文件 | 职责 |
| --- | --- | --- |
| 判定 | `judge.js` | 阈值（2mm / 0.5mm）、轮次合格判定、修整人回避、材料快照比对、交付门禁 |
| 记录 | `records.js` | 试航单开立、初测 / 复测轮次、修整登记、结论失效、读写校验（判定一律委托 `judge.js`） |
| 页面 | `trials-page.js` | `/trials` 配重试航台界面与交互（阈值由 `judge.js` 注入，页面不写规则） |

`server.js` 只负责 HTTP 路由与持久化编排：PATCH 状态为「已交付」时执行交付门禁，配重 / 帆索材料变更时触发旧结论失效。
